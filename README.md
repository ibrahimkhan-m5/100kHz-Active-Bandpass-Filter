# 100 kHz Active Bandpass Filter Design & Implementation

## Project Overview
This repository contains the theoretical design, NI Multisim simulation, and lab project report for an Active Bandpass Filter tuned to a center frequency of 100 kHz.

- Course: EEE 230.1 — Electronics Laboratory
- Department: Electrical & Electronic Engineering (EEE), Southeast University

## Circuit Specifications
- Op-Amp IC: TL072CP
- Power Supply: ±15V DC
- High-Pass Section: R2 = 2.2 kΩ, C1 = 1.2 nF
- Low-Pass Section: R1 = 1 kΩ, C3 = 1 nF
- Gain Resistors: R3 = 10 kΩ, R4 = 10 kΩ

## Calculated Results
- Lower Cutoff Frequency (fL): ~60.3 kHz
- Upper Cutoff Frequency (fH): ~159.2 kHz
- Center Frequency (f0): ~98.0 kHz
- Bandwidth (BW): ~98.9 kHz
- Voltage Gain: 2 (approx +3.24 dB)
